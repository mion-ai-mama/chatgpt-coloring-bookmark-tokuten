# ChatGPTで作る 塗り絵しおり 海外販売スタートガイド（要件定義）

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論・ビルド不要の静的サイト）
- 操作者: ブラウザのエンドユーザー / AI本体: なし / MCP: なし / 自社DB: なし / フロントUI: あり / 動的変数: なし
- 種別: Web型（GitHub Pages） / 配布: マイ専用

## 1. 目的

リールのコメント特典。40代の働くママが、スマホで見ながら ChatGPT で塗り絵しおりを作り、PDFに整え、英語の商品情報を用意して Etsy に出品できるようにする。「必ず売れる」「誰でも稼げる」等は書かない。

## 2. 構成

ファーストビュー（OP画像枠）→ 教科書CTA → 導入 → 完成までの流れ（3STEP）→ はじめる前の準備（チェック）→ もくじ → STEP1（3ジャンル見本・プロンプトA/B/C・修正3つ）→ STEP2（Canva→PDF／英語の商品情報プロンプト／商品画像）→ STEP3（Etsy出品・価格・費用）→【必読】EtsyのAI作品販売ルール → BONUS（商品を増やす）→ よくある質問 → まとめ → 悩み→つなぎ→LINE

デザインは Etsyステッカー特典（chatgpt-etsy-sticker-tokuten）の複製（アイボリー×ブラウン＋くすみピンク）。指示書の「白・黒・グレージュ」は「既存テンプレートの設定を優先」との記載に従い、直近の特典の基準を採用。

## 3. 制作指示書からの差分（理由つき）

- 英語商品情報プロンプトに項目6「AIを使用して制作したことを伝える短い一文」を追加（Etsyの開示義務のため）。他のプロンプトは指示書どおり
- 指示書の「US Letter版」「実際に印刷して確認」は注意として掲載。「Canvaの無料機能の範囲」は未確認のため記載しない
- 画面スクリーンショットは作らず【画像差し替え予定】枠（Canva3枚）。OP画像も同様
- 2026-11-10 しおりサイズ修正: 完成サイズは1本あたり約4.5cm×14cm（縦横比約1:3.1）。プロンプトA/B/Cは縦横比1:3.1・4本同寸・周囲に切り取り余白・外枠からはみ出さない、に変更
- Canva手順: カスタムサイズ（cm）29.7×21（A4横）→画像をページの横幅いっぱいに配置→100％で試し刷り→定規で測り、画像全体を拡大縮小して合わせる。「必ず4.5cmになる」とは書かない（AIの実寸・画像の余白で変わるため）。計算式: 今の画像の幅×4.5÷測った幅
- Canvaの確認範囲: カスタムサイズで単位cmを選べる／「位置」で幅をpx入力できる（公式ヘルプ）。それ以上のUI操作は書いていない

## 4. Etsy公式確認（2026-11-10、実ブラウザで確認。2026-10-28の内容から変更なし）

- クリエイティビティスタンダード（最終更新2025-06-10）: AI作品はセラーオリジナルのプロンプトに基づくもの、商品説明でAI使用の開示が必須。条件を満たさない例: AIプロンプト文例集
- デジタル商品ヘルプ: 最大5点・各20MB。対応形式に .pdf / .zip を含む。ファイル名70文字まで。バリエーション不可
- 商品名は最大140文字、タグは最大13個・各20文字（ヘルプの記載）
- 手数料ポリシー（最終更新2026-10-05）: 出品0.20USD/件（4か月で期限切れ）、取引手数料6.5%。設定料は一回限り・返金不可だが金額は公式に記載なし（ショップ設立時に表示）
- セラーハンドブック「AI作品のスタンス」（2026-10-28確認）: ボット生成の大量自動生成禁止／AIプロンプトのバンドル禁止／商品画像は受け取る内容と同じ／AI使用の商品画像は未修正の実背景写真を最低1枚
- 日本はEtsyペイメント対応国（Payoneerアカウントで対応の注記あり）
